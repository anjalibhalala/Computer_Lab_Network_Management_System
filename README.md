# 🌐 Computer Lab Network Management System

## 📌 About the Project

The Computer Lab Network Management System is a Computer Networks mini-project designed to demonstrate the implementation and management of a computer laboratory network using Cisco Packet Tracer.

## 🎯 Project Objectives

- Design a computer laboratory network.
- Establish connectivity between network devices.
- Configure networking components.
- Understand network communication and management.
- Simulate and test network connectivity.

## 🛠️ Tools Used

- Cisco Packet Tracer
- Computer Networking Concepts

## 🚀 How to Run

1. Download the `.pkt` file from the Packet_Tracer folder.
2. Install and open Cisco Packet Tracer.
3. Open the downloaded project file.
4. Explore the network topology and configurations.
